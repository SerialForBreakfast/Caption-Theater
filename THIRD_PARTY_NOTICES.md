## Media And Fixture Policy

Before making this repository public:

- remove private proof-of-concept media unless redistribution rights are explicit;
- preserve attribution for any retained open-content media;
- keep source URLs and provenance notes for retained fixtures;
- prefer generated fixtures for long-term open-source testing.

## Tears Of Steel

**Removed from the public repository.** The tree previously contained a private proof-of-concept HLS mock derived from a public Mux-hosted Tears of Steel stream, at:

```text
CaptionTheater/CaptionTheater/Media/OfflineHLS/TearsOfSteelFiveMinuteMock/
```

It was removed ahead of open-sourcing because redistribution rights were never cleared and attribution requirements were not fully satisfied (see caveat below). The `CaptionTheaterPlaybackDemoSource.bundledOfflineHLSMock` demo source still exists in code and fails closed with a missing-resource placeholder when this media is absent. Regenerate the mock locally for private development with `Scripts/download_mux_offline_hls_mock.py`; do not re-add it to a public branch unless redistribution has been explicitly cleared and attribution requirements are satisfied.

Relevant upstream attribution:

- Title: Tears of Steel
- Creator / producer: Blender Institute / Blender Foundation
- Project page: https://mango.blender.org/
- Reported license: Creative Commons Attribution 3.0

Important caveat: any regenerated local HLS mock may not include the complete credit scroll and is captured through a hosted stream. That made it unsuitable for public repository distribution, which is why it was removed rather than reviewed and kept.

## Generated Widescreen Fixture

The repository includes a project-owned generated fixture:

```text
CaptionTheater/CaptionTheater/Media/OfflineHLS/CaptionTheaterGeneratedWidescreenFixture/
```

This fixture is generated by `Scripts/generate_widescreen_fixture.py`. It contains synthetic 1920x800 video, timed WebVTT captions, no audio, and no third-party media content. It is intended as the safe default offline demo asset.
